# Data dictionary — synthetic dwell dataset `synthetic-v2`

> **This is synthetic data, not real port history.** It is generated by
> `ml/scripts/generate_synthetic_v2.py` with a fixed seed. Only the per-port, per-direction mean
> dwell is anchored to real published aggregates.

## Files

| File | Rows | Seed | Purpose |
|---|---|---|---|
| `ml/data/raw/synthetic_v2.csv` | 10,000 | 42 | main set |
| `ml/data/raw/synthetic_v2_stress.csv` | 1,500 | 43 | stress holdout: harder conditions, separate seed |
| `ml/data/processed/v2/{train,val,test}.csv` | 7,000 / 1,500 / 1,500 | — | time-ordered split of the main set |
| `ml/data/processed/v2/stress.csv` | 1,500 | — | prepared stress set |

All of these files are git-ignored and rebuilt by the scripts. `prepare_data.py` validates the
schema, nulls, category values and ranges, and fails loudly instead of dropping rows. It also
derives `arrival_day_of_week` and `arrival_month` and drops the raw date.

## Columns

| Column | Type | Values / distribution (main set) | Model feature |
|---|---|---|---|
| `expected_arrival_at` | ISO date-time | uniform over 2025-01-01 to 2026-10-31, at 10:00 UTC | no: used for the split, then replaced by the two columns below |
| `arrival_day_of_week` | string | derived, Monday … Sunday | yes |
| `arrival_month` | string | derived, January … December | yes |
| `port_code` | string | INNSA 60%, INMUN 40% | yes |
| `direction` | string | import 60%, export 40% | yes |
| `cargo_type` | string | general_container 70%, reefer 15%, hazardous 8%, oversized 7% | yes |
| `container_size_ft` | integer | 20: 35%, 40: 65% | yes (numeric) |
| `hs_chapter` | **two-digit string** | uniform over 20 chapters: 02, 08, 29, 84, 85 and 10–24. Always read as text so the zero padding survives. | yes |
| `weight_kg` | number | lognormal (mean 9.5, sigma 1.0 on the log scale), clipped to 500–40,000 | yes |
| `shipping_line` | string | Line A 30%, B 25%, C 20%, D 15%, other 10% | yes |
| `vessel_size_band` | string | small 25%, medium 45%, large 30% | yes |
| `documentation_status` | string | complete 70%, incomplete 20%, unknown 10% | yes |
| `forecast_capacity_utilization_pct` | number | yard utilization from the API's capacity simulator for the port and date; 20% of main rows are moved into 80–98% so congestion is exercised | yes |
| `customs_channel` | string | true channel by importer type (below); recorded as `unknown` for 35% of rows | yes (v2-only) |
| `importer_type` | string | AEO 10%, regular 60%, new 30% | yes (v2-only) |
| `is_holiday` | 0/1 | 1 on 26 Jan, 1 May, 15 Aug, 2 Oct, 25 Dec | yes (v2-only) |
| `exam_queue_len` | integer | `max(0, round(10 + 0.9 × (utilization − 50) + noise))`, noise sd 8 | yes (v2-only) |
| `cargo_priority` | string | government 3%; expedited for 40% of reefer and 5% of other cargo; otherwise standard | yes (v2-only) |
| `dwell_days` | number | **target**, in days, clipped to [0.1, 30] | target |

**Customs channel probabilities by importer type** (green / orange / red):

| Importer type | Green | Orange | Red |
|---|---|---|---|
| AEO | 90% | 8% | 2% |
| regular | 70% | 20% | 10% |
| new | 50% | 30% | 20% |

## How `dwell_days` is built

```
dwell = base(port, direction) × cargo × documentation × congestion × hs × weight × weekend
        × shipping_line × channel × max(importer × priority, 0.5) × holiday × noise
```

| Factor | Values |
|---|---|
| `base` (days) | INNSA import 0.87, INMUN import 1.17, INNSA export 3.14, INMUN export 5.18 |
| cargo | general 1.0, reefer 0.85, hazardous 1.5, oversized 1.8 |
| documentation | complete 1.0, incomplete 1.8, unknown 1.3 |
| congestion | `1 + 1.5 × (max(0, utilization − 70) / 30)²` (about ×2.3 at 98%) |
| hs | chapter 29 ×1.2; 84 and 85 ×1.1; others ×1.0 |
| weight | `1 + weight_kg / 200,000` |
| weekend arrival | ×1.15 |
| shipping line | D ×1.1, other ×1.25, others ×1.0 |
| channel (true value, even when recorded as unknown) | green 1.0, orange 1.2, red `1.4 + 0.01 × exam_queue_len` |
| importer type | AEO 0.75, regular 1.0, new 1.15 (**assumption**) |
| priority | standard 1.0, expedited 0.75, government 0.6 (**assumption**) |
| importer × priority floor | never below ×0.5 |
| holiday | ×1.2 |
| noise | lognormal, sigma 0.35 (**assumption**; it cannot be derived from monthly averages) |

**Calibration:** after generation, dwell is rescaled per port and direction so the main set's mean
equals `base`, then clipped to [0.1, 30]. `ml/scripts/evaluate.py` reports the result
(`ml/reports/calibration_v2.json`): all four means are within 0.2% of the reference. That checks the
data, not the model, and it holds by construction.

## Stress holdout (`synthetic_v2_stress.csv`)

Same generator, shifted parameters, separate seed:
- **cargo:** general 40%, reefer 25%, hazardous 15%, oversized 20%
- **documentation:** complete 50%, incomplete 30%, unknown 20%
- **shipping line:** A 20%, B 20%, C 15%, D 15%, other 30%
- **utilization:** uniform 75–98%
- **disruption scenario:** about 20% of import rows have dwell multiplied by a factor between 2.0 and
  3.0. It mirrors the April–June 2020 lockdown in the reference data, and nothing in the features
  reveals it.
- **calibration:** reuses the main set's scale factors, so the stress set really is harder (v1
  recalibrated it and cancelled the effect).

## Reference data (real aggregates)

The `base` values come from monthly average dwell per port and Import/Export for 2020 and 2021,
excluding the April–June 2020 lockdown:

| Port | Direction | Hours | Days |
|---|---|---|---|
| JNPT (Nhava Sheva) = INNSA | import | 20.9 | 0.87 |
| APSEZ (Adani, Mundra) = INMUN | import | 28.1 | 1.17 |
| JNPT (Nhava Sheva) = INNSA | export | 75.4 | 3.14 |
| APSEZ (Adani, Mundra) = INMUN | export | 124.4 | 5.18 |

They are aggregates, not individual-container ground truth, and are used only for calibration and
the disruption scenario.

### Per-year calibration check

`ml/scripts/evaluate.py` → `ml/reports/calibration_v2.json`. This checks the data, not the model.
The table shows the difference between the simulated mean and each year's real mean (target within
±15%):

| Year | INNSA import | INMUN import | INNSA export | INMUN export |
|---|---|---|---|---|
| 2020 (9 months, lockdown excluded) | +1.0% | −10.2% | +3.4% | +2.1% |
| 2021 (12 months) | −0.8% | +8.9% | −2.6% | −1.9% |
| 2022 (11 months, Jan–Nov; not used for calibration) | −5.8% | +2.6% | +0.6% | +8.7% |

All 12 comparisons are within tolerance. The largest gap is Mundra import in 2020, where the real
mean (31.3 h) is above 2021's (25.8 h), as spec section 10 notes. 2022 was not used to calibrate the
generator, so it acts as an out-of-sample check.

**Lockdown scenario:** JNPT import was 50, 65 and 38 hours in April–June 2020, against 20.7 hours in
the other 2020 months. That's ×1.84 to ×3.15. The stress set's disruption factor (×2.0 to ×3.0)
sits inside that range.

## Changes from `synthetic-v1`

- Convex congestion effect: v1's linear effect was lost in the noise.
- Noise sigma 0.6 → 0.35.
- Stress-set calibration bug fixed.
- HS multiplier bug fixed: v1 tested for chapter 30, which is not in the list.
- Simulator utilization of 0 is no longer treated as missing.
- The five v2-only columns and the busy-utilization share were added.

Full notes are in the generator's docstring.
